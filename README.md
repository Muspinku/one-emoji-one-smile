Entrants send exactly one emoji, the one most likely to make a stranger smile. A judge compares them two at a time and picks the warmer; the emoji that wins the most comparisons takes the reward.

This entry is 🤗 (U+1F917, Hugging Face): a smiling face offering a hug — the most direct gesture of warmth. Instantly readable, universal, no irony, clearly picked rather than the first smiley that comes to mind, and a virtual hug is friendly, not romantic or flirtatious.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18 or later, standard library only — nothing to install. The program writes the entry to `out/entry.txt`.
